# Full-Duplex-Bench-JA batch evaluation manifest.
#
# One model per line, "|"-delimited (NOT comma -- FDB_SEEDS=0,1,2 needs commas
# inside a field):
#   model_id|model_weight|model_config|hf_repo|extra_env|opening_greeting
#
# - model_id       required. Same charset rule as run_full_duplex_eval.sh:
#                   letters, digits, dot, underscore, hyphen only.
# - model_weight    optional. Path to consolidated.safetensors / exported
#                   model.safetensors. Leave empty to use the HF default
#                   weight (e.g. for the base model).
# - model_config    optional. Path to moshi_lm_kwargs.json matching
#                   model_weight. Leave empty for merged LoRA models (same
#                   architecture as the base) or for full-FT exports, since
#                   run_full_duplex_eval.sh auto-detects moshi_lm_kwargs.json
#                   sitting next to model_weight (that's where
#                   scripts/export_fullft_checkpoint.py always writes it).
#                   Only needed if the config lives somewhere else.
# - hf_repo         optional. Overrides HF_REPO for this row only
#                   (default: llm-jp/llm-jp-moshi-v1).
# - extra_env       optional. ";"-separated KEY=VALUE overrides applied only
#                   to this row, e.g. FDB_SEEDS=0,1,2;FDB_TTS_SPEAKER=Ono_Anna
# - opening_greeting optional. "0" or "1", sets FDB_OPENING_GREETING for this
#                   row only. Leave empty to use the default described below.
#                   This dedicated column exists so the greeting toggle
#                   doesn't need to be smuggled through extra_env; it takes
#                   precedence over any FDB_OPENING_GREETING inside extra_env.
#
# FDB_OPENING_GREETING precedence for a row (highest first):
#   1. this row's opening_greeting column
#   2. FDB_OPENING_GREETING=... inside this row's extra_env
#   3. auto-default: a row with empty model_weight (unmodified HF checkpoint,
#      e.g. "base") automatically runs with FDB_OPENING_GREETING=0 -- it was
#      never trained to say the fixed opening line, so nothing needs to be
#      set by hand for that case.
#
# Blank lines and lines starting with # are ignored. Copy this file to
# scripts/models_manifest.txt (or anywhere else) and edit before running:
#
#   qsub -v MODELS_FILE=scripts/models_manifest.txt \
#     scripts/run_full_duplex_eval_batch.pbs
