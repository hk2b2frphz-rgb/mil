# うん に差し替えてよい相槌（最小の継続相槌）だけを並べる。
#
# 相槌には 2 種類あって、うんで代用できるのは片方だけ。
#
#   継続  「聞いている、続けて」しか言っていない。はい / ええ / うん
#   評価  内容についての判断が入る。そうなんですね / なるほど / 大丈夫ですよ
#
# 評価の方を うん に置き換えると、相手の話に対する反応が消えて会話が
# おかしくなる。長さで切ると「なるほど」(4文字) が継続側に混ざるので、
# 文字数ではなく語で決める。
#
# 末尾の句点は落として突き合わせるので、ここには書かない。
はい
はい、はい
ええ
えぇ
ええ、ええ
うん
うん、うん
うんうん
