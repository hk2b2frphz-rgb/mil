# 実データから抜いた相槌例

出典: 孤独孤立相談ダイヤル、タイムスタンプ付き書き起こし（2023-12-29 収録）。
Staff の発話から、相槌でない部分（言い換え・質問・助言）を除いたもの。
このモードが再現したいのは相槌だけなので、それ以外はスコープ外として落として
ある。「除去」列の右が実際に落とした部分。

| Staff の原文 | 残した相槌 | 除去した部分 |
| --- | --- | --- |
| うーん | うーん | (無し。単独) |
| うん | うん | (無し。単独) |
| うんー。例えばその時にね、手をあげられたり叩かれたりしなかったですか？ | うんー | 「例えばその時にね...」以下の質問 |
| うー | うー | (無し) |
| うんうん | うんうん | (無し) |
| そっか、そっか、緊張してます？ | そっか、そっか | 「緊張してます？」 |
| うん | うん | (無し。156秒後にまた単独で出現) |
| そっかー。何年生かな？ | そっかー | 「何年生かな？」 |
| そっか。そっか。 | そっか。そっか。 | (無し。ただし句点区切り=2発話) |
| そっか、この点でも夫さんから責められちゃうってことだね。 | そっか | 「この点でも...」以下の言い換え |
| うーん、そっか。どこか相談いけてる？ | うーん、そっか | 「どこか相談いけてる？」 |
| そっか、そっかー、学校のこととかね、子育てのことは... | そっか、そっかー | 「学校のこととかね...」以下 |
| うん / うーん / う-ん | うん / うーん | (無し。連続で3回出現) |
| そうかー。そういうね、あなたの気持ちを... | そうかー | 「そういうね...」以下の質問 |
| そっか、そっか、ねぇお母さんが怒鳴られてるのを... | そっか、そっか | 「ねぇお母さんが...」以下の解釈 |
| あーそっか。じゃあ | あーそっか | 「じゃあ」以下(次の発話へ継続) |

分かったこと:

- 「そっか」と「そうか」は両方実在する（別の発音）。前回そうかー を落として
  いたのは間違い。
- 「そっかそっか」（区切りなし）と「そっか、そっか」（読点あり）と
  「そっか。そっか。」（句点=2発話として分けている）は別々に出てくる。特に
  句点区切りは、単語を1つ選んで2回別々の位置で言わせれば再現できるもので、
  専用の語彙を持つ必要が無い可能性がある。
- 「そっか、そっかー」「あーそっか」のように、異なる相槌が1つの塊として
  連結して出てくる。今までの語彙にこの組み合わせは無かった。
- 「うんー」（伸ばしが「うん」の後ろに付く）は「うーん」（「う」が伸びる）とは
  別の書き方で実在する。
- 実データの書き起こしには「…」は一度も出てこない（句点・読点・伸ばし棒のみ）。
  「…」を使うこと自体が悪いわけではなく（実際に聞いて効果があったのであれば
  それは合成側の演出として有効）、ただし「これが実データの表記だ」という
  裏付けにはならない。効果が確認できている語にだけ残す。
