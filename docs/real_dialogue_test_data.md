# 実対話テストデータの作り方（人手アノテーション版）

実際のロールプレイ相談音声から、**User 側の発話をテスト入力として切り出す**。
正解は人が付けたアノテーション TSV であり、スクリプトはそれを WAV に切り出す
だけ。ダイアライゼーションも ASR も使わない。

**TSV が正、WAV はその出力**という関係にしてある。TSV を直してもう一度実行
すれば作り直される。

## アノテーション TSV

音声と同じ名前で拡張子だけ `.tsv` にしたものを、音声の隣に置く。

```
/path/dialogue1.wav
/path/dialogue1.tsv
```

| 列 | 内容 |
|---|---|
| `Speaker` | `Staff` または `User` |
| `Transcription` | 人手の書き起こし |
| `Start` | 発話開始。`00:00:15.500` 形式 |
| `End` | 発話終了。同上 |

```
Speaker	Transcription	Start	End
User	もしもし、あの、相談したいことがありまして	00:00:15.500	00:00:21.200
Staff	はい、お伺いします	00:00:21.000	00:00:23.000
```

ヘッダ行はあってもなくてもよい。無ければ上の順に並んでいるものとして読む。
列名は `話者` / `書き起こし` / `開始` / `終了` などの表記ゆれも受ける。

時刻は `HH:MM:SS.mmm` のほか `MM:SS.mmm` / `SS.mmm` も受け、小数点はピリオド
でもカンマでもよい（Excel やツールによって変わるため）。

## 実行

```bash
uv run python scripts/build_test_wav_from_tsv.py /path/dialogue1.wav \
    --out-dir data/real_dialogue/test
```

GPU も NeMo も Whisper も要らない（numpy と soundfile だけ）。ジョブ投入も不要。

出力は `<out-dir>/<wav_stem>/` に:

```
dialogue1/
├── User/0000_00m15.5s_5.7s_ov_もしもしあの相談したいことがあり.wav
├── clips.tsv     採用したもの一覧
└── dropped.tsv   落としたもの一覧（理由付き）
```

## 相槌の除去

「はい」のような相槌も 1 発話として書かれているので、既定では**記号を除いた
文字数が 5 未満の発話を落とす**（`--min-chars 5`）。

落としたものは `dropped.tsv` に理由付きで残るので、閾値が妥当だったか後から
確認できる。5 が厳しすぎ／緩すぎと分かったら値を変えて再実行する。

長音「ー」は文字数に数える。記号ではなく実文字で、除くと「えーっと」が 3 文字
になり、相槌でない発話まで落ちてしまう。

`--min-sec` で長さによる足切りもできる（既定 0 = 無効）。

## 重畳区間

1ch 録音なので、User の発話が Staff の発話と重なっている区間では**相手の声が
同じ標本に混ざっており、消せない**。

該当するクリップはファイル名に `_ov` が付き、`clips.tsv` の `overlap_sec` 列に
秒数が出る。ジョブの最後にも件数を警告として出す。相手の声が混ざって困るものは
そこを見て外すこと。

`--mute-other` を付けると、切り出した区間のうち**相手だけが喋っている部分**を
無音化する。重畳部そのものは消せないので、これは補助でしかない。

## 主なオプション

| オプション | 既定 | 意味 |
|---|---|---|
| `--out-dir` | `data/real_dialogue/test` | 出力先ルート |
| `--speaker` | `User` | 切り出す話者ラベル。大文字小文字は区別しない |
| `--min-chars` | `5` | 記号を除いた文字数がこれ未満なら落とす。0 で無効 |
| `--min-sec` | `0.0` | これより短い発話を落とす。0 で無効 |
| `--mute-other` | off | 相手だけが喋っている部分を無音化 |
| `--annotation` | WAV と同名 `.tsv` | TSV を明示指定（WAV 1 つのときのみ） |

出力ディレクトリ名は `--speaker` の綴りではなく **TSV 上の実ラベル**を使う。
`--speaker staff` と `--speaker Staff` で別フォルダができると混乱するため。

## 停止する条件

黙って通すと結果が静かに壊れるものは、**WAV を 1 つも書く前に**行番号付きで
報告して停止する。

- `End <= Start` の行
- 時刻の形式が不正な行
- 列数が足りない行
- 指定した話者ラベルの発話が 1 件も無い（TSV にあるラベル一覧を出す）
- アノテーション TSV が見つからない

TSV の最終時刻が音声長を超えている場合は、音声と TSV の組み合わせ違いを疑って
警告を出す（停止はしない）。
